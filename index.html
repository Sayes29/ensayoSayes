DESPLIEGUE RÁPIDO

Publica tu primera página

En Debian o Ubuntu, puedes usar el directorio web por defecto de Nginx. Estos comandos son una guía básica; adapta la ruta si tu configuración utiliza otro root.

1
Instala Nginxsudo apt update && sudo apt install nginx
2
Copia el archivosudo cp index.html /var/www/html/
3
Comprueba la configuraciónsudo nginx -t
4
Recarga el serviciosudo systemctl reload nginx
